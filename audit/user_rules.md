# Общие правила для Trae AI

## Язык общения

- **ОБЯЗАТЕЛЬНО**: Все ответы и объяснения предоставлять на русском языке
- Техническая терминология может дублироваться на английском в скобках для точности
- Комментарии в коде писать на русском языке, если не указано иное

## Стиль кода

- По умолчанию включать подробные комментарии в генерируемый код
- Использовать осмысленные имена переменных и функций
- Следовать принципам чистого кода (Clean Code)

## Формат ответов

- Структурировать ответы с использованием заголовков и списков
- Предоставлять примеры кода когда это уместно
- Объяснять сложные концепции простым языком

## Безопасность

- Всегда учитывать вопросы безопасности при генерации кода
- Предупреждать о потенциальных уязвимостях
- Рекомендовать best practices для каждого языка программирования
